OSDM capture

Page media

Start playback, then scan again for recently loaded media. Choose one offer; nothing is captured automatically. No cookies are sent.

DRM, blob-only players, hidden JavaScript sources, and inaccessible frames are unsupported. This does not crawl playlists or change browser playback.
Enable browser integration in OSDM and register the native host first. Automatic capture sends no cookies.

Cookies are handed off only from the explicit context-menu action, for the selected URL. They are never stored by this extension. If OSDM is unavailable, automatic capture leaves your browser download alone.
